# Security Policy

This is an early-stage portfolio project and does not yet promise production-grade support.

## Reporting
Do not publish exploit details or upload private documents in a public issue. Use a private repository security advisory if available, or a verified private maintainer contact. Include affected version/commit, impact, reproducible steps, and a minimal non-sensitive proof of concept.

## Scope
Relevant issues include arbitrary file access, path traversal, unsafe parsing, credential exposure, unauthorized document access, remote data leakage, citation validation bypass, and XSS.

Do not test against systems you do not own. Harden the application before public deployment.
